# 🔗 Binev Short URL — Joomla 6 System Plugin

پلاگین سیستمی جوملا ۶ برای ایجاد لینک کوتاه خودکار مطالب.

## ✨ ویژگی‌ها

- 🔹 ایجاد خودکار لینک کوتاه هنگام ذخیره مطلب
- 🔹 ریدایرکت خودکار `yoursite.com/?s=CODE` → مطلب اصلی
- 🔹 نمایش لینک کوتاه در فرم ویرایش (باکس آبی + دکمه کپی)
- 🔹 نمایش لینک کوتاه در صفحه نمایش مطلب (بالای محتوا)
- 🔹 پیام سیستم پس از ذخیره با لینک کوتاه
- 🔹 پیشوند اختیاری + طول قابل تنظیم + ۳ نوع کاراکتر
- 🔹 ریدایرکت فقط به مطالب منتشر شده (state=1)
- 🔹 کد تصادفی یک‌بار ایجاد شده و با هر ذخیره تغییر نمی‌کند
- 🔹 سازگار با جوملا ۶ (PHP 8.3+)

## 📦 نصب

1. فایل ZIP رو از [Releases](../../releases) دانلود کنید
2. جوملا → افزونه‌ها → نصب
3. فایل ZIP رو آپلود کنید
4. افزونه رو فعال کنید

## ⚙️ تنظیمات

افزونه‌ها → مدیریت افزونه‌ها → System - Short URL → تب Options

| تنظیم | توضیح | پیش‌فرض |
|--------|--------|---------|
| **Prefix** | پیشوند اختیاری. خالی = کد تصادفی. بخشی از طول کل کد | — |
| **Code length** | تعداد کل کاراکترها شامل پیشوند (۴–۱۰) | ۶ |
| **Character set** | حروف، اعداد، یا هر دو | Alphanumeric |

### مثال پیشوند

| پیشوند | طول کد | نمونه خروجی |
|--------|--------|------------|
| خالی | ۶ | `xK9m2B` |
| `ab` | ۶ | `ab7P3n` |
| `post` | ۸ | `post4Kx1` |

## 📖 نحوه استفاده

### ایجاد خودکار
مطلب رو ایجاد یا ویرایش کنید → پس از ذخیره لینک کوتاه خودکار ایجاد میشه.

### مطالب موجود
مطلب قبلی رو باز کنید → لینک کوتاه **خودکار** ایجاد میشه (نیازی به ذخیره مجدد نیست).

### نمایش در سایت
در صفحه نمایش مطلب، باکس آبی با لینک کوتاه و دکمه کپی زیر اطلاعات مطلب نمایش داده میشه.

### ریدایرکت
```
https://yoursite.com/?s=abc123  →  https://yoursite.com/مطلب-شما
```

## 🗄️ دیتابیس

پلاگین یک جدول `#__shorturl` ایجاد می‌کنه:

| ستون | نوع | توضیح |
|------|------|--------|
| `id` | INT(11) PK | شناسه |
| `article_id` | INT(11) | شناسه مطلب |
| `short_code` | VARCHAR(50) UNIQUE | کد کوتاه |
| `created` | DATETIME | تاریخ ایجاد |
| `modified` | DATETIME | تاریخ آخرین تغییر |

## 📁 ساختار فایل‌ها

```
shorturl.xml        ← مانیفست (ریشه زیپ)
shorturl.php        ← فایل اصلی پلاگین
forms/article.xml   ← فیلد hidden در فرم مطلب
sql/install.sql     ← ایجاد جدول
sql/uninstall.sql   ← حذف جدول
language/en-GB/     ← زبان انگلیسی
language/fa-IR/     ← زبان فارسی
```
